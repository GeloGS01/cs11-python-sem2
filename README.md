# CS11 Python - Sem2

Grade 11 (11IS / 11IB) Python projects, run in GitHub Codespaces.

## Open your Codespace
1. Click the green **Code** button -> **Codespaces** tab -> **Create codespace on main**.
2. Wait for it to finish setting up (the first time takes 2-3 minutes).

## Run a program
In the terminal at the bottom:
```
python test_setup.py
```
or open a `.py` file and click the play button at the top-right.

## Seeing GUI (tkinter) windows
1. Open the **Ports** tab (next to Terminal).
2. On the row **GUI Desktop (port 6080)**, click the globe icon to open it in a new browser tab.
3. Click **Connect** and enter the password: `vscode`
4. Run your program - the window appears on that desktop.

## Saving your work
Your files stay in your Codespace, but **commit before you leave** so they are saved to GitHub for good:
1. Click the **Source Control** icon on the left (branch symbol).
2. Type a message like `Lesson 1 done`, then click **Commit**, then **Sync Changes**.

Then **sign out of GitHub** before you log off the iMac.
